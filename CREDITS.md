## Note on hosting images

The hero image is currently hot-linked from Wikimedia Commons, so it requires an
internet connection to display and depends on that file remaining available. For
maximum reliability you can download the image, place it in an `images/` folder
in this repository, and update the `src` in `index.html` to point at the local
file (e.g. `images/hero-tulips.jpg`).
